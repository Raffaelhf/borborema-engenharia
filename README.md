# Borborema Engenharia

Material de preparação do site institucional da Borborema Engenharia em WordPress.

## Conteúdo desta versão

- `AGENTS.md`: instruções de desenvolvimento, conteúdo e manutenção.
- `Referencias_Sites_Borborema_Engenharia.md`: briefing original, preservado.
- Pastas de obras: fotografias, vídeos e notas recebidos para análise do portfólio, com nomes e estrutura originais preservados.

As pastas `modelo-site/`, `design/` e `wordpress/` mencionadas no `AGENTS.md` não estão presentes nesta cópia. Esta versão não contém um site executável, tema ou plugin WordPress e não possui comandos de instalação, build ou teste.

## Uso do material

Nomes das pastas e fotografias não confirmam o escopo executado, datas, clientes autorizados ou permissão de divulgação. Validar informações e autorizações antes de usar o material no site público.

Manter este repositório privado enquanto as permissões de divulgação estiverem pendentes. O envio ao GitHub serve para versionamento; não publica nem altera o WordPress de homologação.

## Desenvolvimento

Consultar `AGENTS.md` e o briefing antes de implementar alterações. A plataforma definida é WordPress, com Elementor gratuito. Credenciais, configurações privadas e exportações de banco de dados devem permanecer fora do repositório.
